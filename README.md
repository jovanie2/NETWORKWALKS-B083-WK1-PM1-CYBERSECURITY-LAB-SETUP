# NETWORKWALKS-B083-WK1-PM1-CYBERSECURITY-LAB-SETUP
This repo documents the process of me setting up my isolated virtual lab for ethical hacking practices and penetration testing. 
# Project Overview
This project focuses on the setting up of a virtual cybersecurity and penetration-testing lab using VirtualBox and Kali Linux.
The intent was to create a controlled environment where cybersecurity tools, network scanning, reconnaissance, vulnerability assessment, and other security-testing activities can be conducted safely and repeatedly.
This was done on a private virtual network so that additional machines can be further added and used as targets for authorized security testing.
# What was done?
7-zip was installed to unzip the Kali Linux

The VirtualBox Manager was installed

A NAT Network was created 

Kali network connectivity was configured and troubleshooted

An IP address was assigned to the Kali Virtual Machine

A clean snapshot and all the other instructions were closely followed ensuring the environment is same as that of the instructor.
